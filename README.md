# spring-boot-user-management
User management REST API with Spring Boot, JPA/Hibernate, MySQL, Spring Security, JWT authentication, validation, pagination, and exception handling.

# Spring Boot User Management API

Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT
- Docker

Features
- User CRUD
- Pagination & Search
- Input Validation
- Global Exception Handling
- Authentication & Authorization
- JWT-based Security
- Role-based Access Control
